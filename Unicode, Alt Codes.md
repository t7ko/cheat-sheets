# Alt-X Codes

How to enable:

- Enable extended Unicode input by adding a Registry entry to allow hex input:
    - Run `regedit`
    - Navigate to `HKEY_CURRENT_USER\Control Panel\Input Method`
    - Create a new **String Value** called `EnableHexNumpad`
    - Set its value to `1`
    - Restart Windows for the change to take effect

How to use:

- To enter Unicode char, do `Alt + KeyPad Plus` then type Unicode hex, then release `Alt`.
